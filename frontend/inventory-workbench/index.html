Honest Data Rules

  1. Never call HTTP 200 alone "success".
  2. Do not auto-delete web page links; web pages are PROVENANCE_OR_NAVIGATION.
  3. Distinct derivative contracts (Stock Opt vs Stock Fut vs BankNifty) are separate datasets.
  4. Cross-board consensus uses the guarded TrendForge panel snapshot. If it is unavailable or stale, cached voting records are blocked. Not financial advice.
  5. Standard feeds do not include option greeks (delta/gamma/theta/vega/IV).
  6. Add future consensus voters via consensus_plugins.js without editing the engine core.
