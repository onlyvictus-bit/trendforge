TrendForge

Research scanner for NSE/BSE/MCX. Scan stocks through gates and scores. Radar shows research results. No broker orders.

RESEARCH ONLY · ACTIVATION OFF
The Path: Outside data is monitored and parsed, gates block activation, scanner runs symbols through structure and evidence, causal scores, radar shows wait/reject research results. Boss: SCANNER SCHEDULER.

How they talk

  1. EXTERNAL MARKETS send raw files to SOURCE MONITOR so monitor can check freshness.
  2. SOURCE MONITOR sends archives to SOURCE PARSER so rows become clean.
  3. INVENTORY COMPILER sends activation rules to GATE READINESS so gates can block confirm.
  4. GATE READINESS sends blocked flags to SCANNER SCHEDULER so all symbols stay research-safe.
  5. SCANNER SCHEDULER sends work to SAFETY and MARKET CONTEXT so mood and locks apply.
  6. OHLCV STORAGE sends candles to CORPORATE ACTIONS then HARMONIC ENGINE so charts stay honest.
  7. FEATURE ENGINE and EVIDENCE BUILDER send numbers/claims to CAUSAL ENGINE so it can score.
  8. CAUSAL ENGINE sends states to SQLITE STORAGE so the diary keeps the run.
  9. SQLITE STORAGE sends latest run to RADAR ENGINE so FRONTEND can paint the list.
  10. FRONTEND PANEL sends run-once to FASTAPI SERVER so SCANNER SCHEDULER starts the boss path.
