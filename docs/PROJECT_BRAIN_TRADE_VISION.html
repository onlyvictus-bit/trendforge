Trade Vision

Paper guidance desk. One symbol freezes, scores, Arbiter judges, card shows. Live trading blocked.

PAPER ONLY · NO LIVE ORDERS
The Path: Local candles get cleaned, frozen, scored by evidence and ORB, judged by Arbiter, shown on screen, optionally saved as fake trades. Boss: ARBITER.

How they talk

  1. CANDLE SOURCE sends raw bars to UI BUILD so UI BUILD can clean them.
  2. UI BUILD sends payload to HTTP IN so server can run paper guidance.
  3. HTTP IN sends request to SNAPSHOT FREEZE so past data locks hard.
  4. SNAPSHOT FREEZE sends frozen bars to EVIDENCE PACK so tools can score.
  5. SNAPSHOT FREEZE sends frozen bars to ORB PLAYBOOK so it can propose a plan.
  6. EVIDENCE PACK and ORB send scores/plan to ARBITER so boss can judge.
  7. SAFETY sends stop flags to ARBITER so bad days cannot ENTER_PAPER.
  8. ARBITER sends decision to GUIDANCE OUT so UI gets a clean JSON card.
  9. GUIDANCE OUT sends card to UI SCREEN so user can read the answer.
  10. UI SCREEN sends record click to PAPER LEDGER so fake trades save; OUTCOME WATCHER later checks win/loss.
